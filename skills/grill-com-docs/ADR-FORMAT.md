# Formato de ADR

ADRs em **`$WORK/docs/adr/`**: `0001-slug.md`, `0002-slug.md`, …  
`$WORK` = `~/.agents/work/<marca>/` — ver [../work-path.md](../work-path.md).  
Criar a pasta só no primeiro ADR.

## Template

```md
# {Título curto da decisão}

{1–3 frases: contexto, o que decidimos, por quê.}
```

## Opcional

Status, opções consideradas, consequências — só se agregarem valor.

## Numeração

Maior número em `$WORK/docs/adr/` + 1.

## Quando oferecer

Os três: difícil reverter · surpreende sem contexto · trade-off real. Senão, pule.
