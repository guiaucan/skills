# Formato do CONTEXT.md

```md
# {Nome do contexto}

{Uma ou duas frases: o que é e por que existe.}

## Language

**Termo**:
O que É (1–2 frases).
_Avoid_: sinônimo1, sinônimo2
```

## Regras

- Um termo canônico; resto em `_Avoid_`
- Curto: o que É, não o que faz
- Só conceitos deste contexto (não programação geral)

## Onde fica

**`$WORK/CONTEXT.md`** (mapa: `$WORK/CONTEXT-MAP.md` se houver vários contextos).  
`$WORK` = `~/.agents/work/<marca>/` — ver [../work-path.md](../work-path.md).

Criar de forma preguiçosa quando o primeiro termo for resolvido.
